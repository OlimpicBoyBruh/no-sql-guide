# Словарь терминов Cassandra

Искать в документации Apache Cassandra, в справке драйвера DataStax и в поиске нужно по английскому термину, поэтому он указан для каждой строки: «token range» находит нужное, «дуга» — нет.

| Термин | English | Что это | Подробно |
|---|---|---|---|
| **ALLOW FILTERING** | ALLOW FILTERING | Разрешение отбросить лишние строки после чтения, а не сузить чтение по ключу; почти всегда сигнал ошибки модели | [04](04-data-model.md#что-можно-указать-в-where) |
| **Batchlog** | batchlog | Системная таблица, куда logged batch пишет намерение до рассылки мутаций, чтобы координатор мог дожать пакет после сбоя | [08](08-lwt-batches-counters.md#пакеты) |
| **Commit log** | commit log | Последовательный журнал на диске: туда мутация попадает до memtable и переживает падение узла | [02](02-write-read-path.md#запись-commitlog-и-memtable), [фон](../../docs/00-foundations/07-storage-engines.md) |
| **gc_grace_seconds** | gc_grace_seconds | Сколько надгробие обязано прожить, прежде чем уплотнение вправе его выбросить (по умолчанию 864000 с) | [07](07-tombstones.md#зачем-десять-суток) |
| **Gossip** | gossip | Протокол, которым узлы разносят друг о друге состояние членства, поколение и heartbeat | [01](01-architecture.md#gossip-и-детектор-отказов), [фон](../../docs/00-foundations/06-consensus-membership.md) |
| **HOCON** | HOCON | Формат файла `application.conf`, которым переопределяют `reference.conf` драйвера | [10](10-java-driver.md#конфигурация-и-профили-выполнения) |
| **LCS** | LeveledCompactionStrategy (LCS) | Стратегия уплотнения по уровням: бережёт чтение ценой усиления записи | [03](03-compaction.md#lcs) |
| **Memtable** | memtable | Отсортированная структура свежих мутаций в памяти реплики | [02](02-write-read-path.md#запись-commitlog-и-memtable), [фон](../../docs/00-foundations/07-storage-engines.md) |
| **NetworkTopologyStrategy** | NetworkTopologyStrategy | Стратегия репликации: RF задаётся отдельно на каждый дата-центр, реплики стараются класть в разные стойки (rack) | [01](01-architecture.md#кто-хранит-реплики) |
| **Paxos** | Paxos | Протокол консенсуса, на котором работает условная запись одной партиции | [08](08-lwt-batches-counters.md#что-именно-обещает-paxos), [фон](../../docs/00-foundations/06-consensus-membership.md) |
| **SAI** | Storage-Attached Index (SAI) | Вторичный индекс Cassandra 5, который лежит рядом с SSTable и уплотняется вместе с ними | [09](09-indexes-sai.md#sai) |
| **Seed** | seed | Узел, чей адрес прописан заранее, чтобы новичок нашёл вход в gossip | [01](01-architecture.md#gossip-и-детектор-отказов) |
| **SimpleStrategy** | SimpleStrategy | Стратегия репликации: реплики кладутся по кольцу подряд, без учёта дата-центра и стойки; не годится для нескольких дата-центров | [01](01-architecture.md#кто-хранит-реплики) |
| **Snitch** | snitch | Компонент, который сообщает дата-центр и стойку узла; от него зависит расстановка реплик | [01](01-architecture.md#snitch-и-дата-центр) |
| **SSTable** | SSTable (sorted string table) | Неизменяемый файл данных на диске, упорядоченный по ключу партиции и кластерным колонкам | [02](02-write-read-path.md#сброс-в-sstable), [фон](../../docs/00-foundations/07-storage-engines.md) |
| **STCS** | SizeTieredCompactionStrategy (STCS) | Стратегия уплотнения по размеру файлов: бережёт запись ценой числа файлов на чтении | [03](03-compaction.md#stcs) |
| **TTL** | TTL (time to live) | Срок жизни ячейки; по истечении она становится надгробием | [07](07-tombstones.md#ttl-тоже-оставляет-метку) |
| **TWCS** | TimeWindowCompactionStrategy (TWCS) | Стратегия уплотнения по временным окнам: протухшее окно удаляется файлом целиком | [03](03-compaction.md#twcs) |
| **UCS** | UnifiedCompactionStrategy (UCS) | Единая стратегия Cassandra 5: одним параметром масштаба ведёт себя ближе к STCS или к LCS | [03](03-compaction.md#ucs) |
| **Анализатор индекса** | index analyzer | Разбор текста на термы, от которого зависят `LIKE` и оператор `:`; опция `index_analyzer` на `cassandra:5.0` не поддержана | [09](09-indexes-sai.md#sai) |
| **Анти-компакция** | anti-compaction | Разбивка SSTable на «уже сверенную репаиром» и «ещё нет» часть; на ней построен инкрементальный repair | [06](06-consistency-repair.md#anti-entropy-repair) |
| **Анти-энтропийная починка** | anti-entropy repair | Плановая сверка реплик по диапазонам токенов через `nodetool repair` | [06](06-consistency-repair.md#anti-entropy-repair), [фон](../../docs/00-foundations/04-replication.md) |
| **Бакетирование** | bucketing | Добавление искусственной части в ключ партиции (день, час), чтобы партиция не стала широкой | [04](04-data-model.md#бакет), [фон](../../docs/00-foundations/05-partitioning.md) |
| **Баллот** | ballot | Timeuuid, которым Paxos нумерует попытку условной записи: реплики обещают не принимать баллот меньше обещанного, и этим отсекаются опоздавшие претенденты на ключ | [08](08-lwt-batches-counters.md#paxos-по-раундам) |
| **Блокирующий read repair** | blocking read repair | Read repair, который дочитывает разошедшиеся реплики и ждёт результата до ответа клиенту (свойство таблицы `read_repair = BLOCKING`, значение по умолчанию) | [06](06-consistency-repair.md#read-repair) |
| **Векторный поиск** | vector search / approximate nearest neighbor (ANN) | Поиск ближайших векторов средствами SAI в Cassandra 5 | [09](09-indexes-sai.md#векторный-поиск) |
| **Виртуальный узел** | vnode (virtual node) | Один из нескольких диапазонов токенов, которыми владеет физический узел | [01](01-architecture.md#виртуальные-узлы), [фон](../../docs/00-foundations/05-partitioning.md) |
| **Воскрешение удалённых данных** | data resurrection (zombie) | Возврат удалённой строки отставшей репликой после того, как живые узлы выбросили надгробие | [07](07-tombstones.md#что-записывается-вместо-удаления) |
| **Вторичный индекс** | secondary index (2i) | Индекс по неключевой колонке; без ключа партиции запрос разъезжается по кластеру | [09](09-indexes-sai.md#старый-вторичный-индекс) |
| **Гранулярность уборки** | garbagecollect granularity (ROW / CELL) | Ключ `-g` у `nodetool garbagecollect`: `ROW` (по умолчанию) убирает удалённые партиции и строки, `CELL` дополнительно вычищает перекрытые и удалённые отдельные ячейки | [07](07-tombstones.md#пороги-узла-и-ручная-уборка) |
| **Дайджест** | digest | Короткий хеш строки, которым координатор сравнивает реплики, не таща полные данные | [02](02-write-read-path.md#дайджест-и-несколько-реплик) |
| **Действие со схемой** | `schema-action` | Что Spring Data делает со схемой на старте: `NONE`, `CREATE`, `CREATE_IF_NOT_EXISTS`, `RECREATE`, `RECREATE_DROP_UNUSED` | [10](10-java-driver.md#пять-значений-schema-action) |
| **Денормализация** | denormalization | Осознанное дублирование полей и фактов между таблицами ради чтения одним запросом | [05](05-query-first.md#один-факт-две-таблицы), [фон](../../docs/00-foundations/08-data-modeling.md) |
| **Дерево Меркла** | Merkle tree | Хеш-дерево диапазона, по которому repair находит расхождения между репликами | [06](06-consistency-repair.md#anti-entropy-repair) |
| **Диаграмма Чеботко** | Chebotko diagram | Нотация логической и физической модели: у колонки помета **K** (ключ партиции), **C↑** / **C↓** (кластерная и её порядок) или **S** (статическая); стрелки показывают, какой запрос обслуживает таблица и какой факт пишется сразу в несколько | [05](05-query-first.md#артефакт-второй-диаграмма-чеботко) |
| **Диапазон токенов** | token range | Отрезок кольца, которым владеет узел; то, что в аналогии называют «дугой» | [01](01-architecture.md#кольцо-и-токен), [фон](../../docs/00-foundations/05-partitioning.md) |
| **Загрузчик конфигурации** | `DriverConfigLoader` | Источник настроек драйвера: `fromClasspath`, `fromFile`, `fromString`, `fromMap`, `programmaticBuilder`, `compose` | [10](10-java-driver.md#конфигурация-и-профили-выполнения) |
| **Запрос Top-K** | top-K query | Запрос «верхние K по близости» (`ORDER BY ... ANN OF ... LIMIT`); на 5.0 `LIMIT` обязателен и не больше 1000 | [09](09-indexes-sai.md#векторный-поиск) |
| **Идемпотентность запроса** | request idempotence | Признак «повтор безопасен»; `basic.request.default-idempotence = false`, то есть по умолчанию драйвер не повторяет | [10](10-java-driver.md#асинхронность-и-политики) |
| **Идентификатор потока** | stream id | Номер, по которому драйвер мультиплексирует запросы в одном соединении; их до `max-requests-per-connection` = 1024 | [10](10-java-driver.md#пулы-соединений) |
| **Индекс партиций** | partition index | Служебная структура внутри SSTable: где в файле лежит нужный ключ партиции | [02](02-write-read-path.md#сброс-в-sstable) |
| **Инкрементальный repair** | incremental repair | Repair после Cassandra 4: сверяет только данные, не помеченные анти-компакцией как уже проверенные; гоняют регулярно | [06](06-consistency-repair.md#anti-entropy-repair) |
| **Кардинальность** | cardinality | Число различных значений колонки; определяет, уместен ли на ней SAI (середина и низкая частота — рабочая зона) | [09](09-indexes-sai.md#старый-вторичный-индекс) |
| **Кворум** | quorum | Большинство реплик партиции, `floor(RF / 2) + 1`; при RF = 3 это 2 | [06](06-consistency-repair.md#уровни), [фон](../../docs/00-foundations/04-replication.md) |
| **Кластерная колонка** | clustering column | Часть первичного ключа, которая задаёт порядок строк внутри партиции | [04](04-data-model.md#первичный-ключ), [фон](../../docs/00-foundations/08-data-modeling.md) |
| **Кластерный порядок** | clustering order | Свойство таблицы (`CLUSTERING ORDER BY`), а не запроса: на диске строки уже отсортированы | [04](04-data-model.md#порядок-внутри-партиции) |
| **Ключ партиции** | partition key | Часть первичного ключа, от которой считается токен; определяет, какие узлы хранят строку | [04](04-data-model.md#первичный-ключ), [фон](../../docs/00-foundations/05-partitioning.md) |
| **Кольцо** | ring | Замкнутое пространство токенов, по которому распределены все данные кластера | [01](01-architecture.md#кольцо-и-токен), [фон](../../docs/00-foundations/05-partitioning.md) |
| **Координатор** | coordinator | Узел, принявший запрос клиента: он находит реплики и собирает их ответы | [01](01-architecture.md#координатор) |
| **Кэш ключей** | key cache | Кэш позиций партиций в SSTable; включён по умолчанию и обычно полезен | [02](02-write-read-path.md#кэши) |
