# Задания по Cassandra

Условие каждого задания — файл `NN-*.md` в этом каталоге. Код пишется в `src/main/java` этого модуля. Тесты уже лежат в `src/test/java` и ходят в настоящую Cassandra.

Эталонные решения — в `cassandra/solutions`, с теми же именами классов. Не открывайте их, пока свои тесты не станут зелёными.

В заданиях 01–07 незаполненный метод бросает `UnsupportedOperationException` с текстом `TODO`. В задании 08 методы сервиса уже вызывают репозиторий: красными будут проверки маппинга, а не `TODO`. Задание 07 помечено `@Tag("slow")` и в обычный прогон не входит.
