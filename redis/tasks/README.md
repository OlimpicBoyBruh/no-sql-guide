# Задания по Redis

Условие каждого задания — файл `NN-*.md` в этом каталоге. Код пишется в `src/main/java` этого модуля. Тесты уже лежат в `src/test/java` и ходят в настоящий Redis.

Эталонные решения — в `redis/solutions`, с теми же именами классов. Не открывайте их, пока свои тесты не станут зелёными. Эталон нужен, чтобы свериться, если застряли, а не чтобы списать.

В заданиях 01–07 незаполненный метод бросает `UnsupportedOperationException` с текстом `TODO`. В задании 08 методы уже работают без кэша: красными будут проверки аннотаций и `CacheConfig`, а не `TODO`.
